# 演示指令

> 使用前准备：打开 Blender，默认 Cube 场景即可。在 AI Assistant 面板输入指令 → 点「发送」→ 预览代码 → 点「运行」。
> 推荐先把 .blend 保存到项目目录，这样日志和预设都会自动落在项目文件夹里。

---

## 1. 基础代码生成

```
在原点创建一个半径为 1.5 的球体，并给它一个红色材质
```

```
选中所有网格物体，给每个添加一个 Subdivision Surface 修改器，细分级别设为 2
```

```
把场景中所有物体沿 X 轴排列，间距为 3，从 X=0 开始
```

## 2. 多轮对话（上下文记忆）

先发送第一句，紧接着发送第二句（不要清空对话）：

```
创建一个立方体，位置在 (0, 0, 2)
```

```
把刚才那个立方体的缩放设为 (2, 0.5, 2)，再给它加一个 Wireframe 修改器
```

面板显示 "(2 轮)"，AI 能引用前一轮创建的物体。

## 3. Function Calling 工具调用

勾选「工具调用模式」开关后发送：

```
在 (3, 0, 0) 创建一个球体
```

```
创建三个立方体，位置分别在 (0,0,0)、(2,0,0)、(4,0,0)，然后全部设为线框显示
```

日志显示 [TOOL] 标签，AI 通过预置工具执行。

## 4. 错误自动修复

勾选「错误自动修复」开关后发送：

```
创建一个球体，然后设置它的 location 为 (abc, 0, 0)
```

日志显示代码失败 → [FIX] 第1轮自动修复 → AI 修正后重试。

## 5. 代码编辑联动

```
创建一个十二面体形状的经纬球，细分 64 段，在物体模式下应用 Shade Smooth
```

AI 生成后点「在文本编辑器中打开」→ 在 Text Editor 中把 64 改成 16 → 回面板点「运行」。

## 6. 项目日志记录

保存 .blend 文件到某个目录后，随意发送几条指令。然后在操作日志区域点「日志」按钮 → 资源管理器打开 `blender_ai_logs/` 文件夹 → 打开 `blender_ai_commands.log` 查看记录。

每条记录包含：时间戳、你的指令、AI 生成的代码、执行结果。

## 7. 预设系统

执行以下指令，每次成功后点「保存为预设」：

```
创建 10 个立方体，排列成 2x5 的网格，间距 2.5
```
保存为 "网格排列"

```
给所有选中的物体随机分配红/蓝/绿/黄/白五种颜色之一
```
保存为 "随机着色"

```
把所有物体缩放设为 (1, 1, 2)，然后应用缩放
```
保存为 "拉伸并应用"

然后：
1. 点「+新建」创建预设组 "场景批量处理"
2. 依次点击三个预设旁边的 [+] 按钮加入组
3. 点「运行「场景批量处理」」→ 三步顺序执行

## 8. 预设跟随项目

1. 确认 .blend 已保存 → 点预设库标题栏的「同步预设到项目」按钮
2. 新建一个 .blend 文件并保存到另一个目录 → 预设自动切到那个项目的预设
3. 回到之前的 .blend → 预设恢复到之前积累的内容

## 9. 导出 / 导入

点预设库导出图标 → 保存 JSON → 在新场景中点导入图标 → 选"替换"或"合并"。
